Device Trust & Installation Guide

Select your operating system to view exact, step-by-step trust instructions.

Method 1: 1-Line Automated PowerShell Install (Recommended)

Open PowerShell as Administrator and run this single command to download and trust the CA instantly:

irm {{ base_url }}/install.ps1 | iex

Method 2: Windows Command Line (certutil)

certutil -addstore -f "ROOT" rajlabs-root-ca.crt

Method 3: Manual GUI Import

  1. Download rajlabs-root-ca.crt.
  2. Press Win + R, type certmgr.msc and press Enter.
  3. Right-click Trusted Root Certification Authorities → All Tasks → Import.
  4. Click Next, browse to the downloaded certificate file, and complete the wizard.

Apple iOS / iPadOS Onboarding (2-Step Process)

Step 1: Download & Install Profile

Open this page in Safari and tap below:

Download iOS Profile

When prompted, tap Allow → Go to Settings → Tap Profile Downloaded at top → Tap Install.

Step 2: Enable Full Trust (Crucial on iOS!)

By default iOS installs profiles but requires explicit full trust toggle:

  1. Open Settings → General → About.
  2. Scroll to the very bottom and tap Certificate Trust Settings.
  3. Under Enable full trust for root certificates, toggle {{ org_name }} Root CA to ON.

Android Certificate Installation

  1. Download rajlabs-root-ca.crt to your device.
  2. Open device Settings → Security (or Security & Privacy).
  3. Tap More Security Settings → Encryption & Credentials.
  4. Tap Install a certificate → CA certificate.
  5. If prompted with a warning, tap Install anyway.
  6. Select the downloaded rajlabs-root-ca.crt file.

Automated 1-Liner: Auto-Detects Ubuntu, Debian, RHEL, Fedora, Arch, Alpine

curl -fsSL {{ base_url }}/install.sh | sudo bash

Manual Commands by Distribution

Ubuntu / Debian:

sudo curl -fsSL {{ base_url }}/api/v1/ca/root/cert -o /usr/local/share/ca-certificates/rajlabs-root-ca.crt
sudo update-ca-certificates

RHEL / CentOS / Fedora / Rocky:

sudo curl -fsSL {{ base_url }}/api/v1/ca/root/cert -o /etc/pki/ca-trust/source/anchors/rajlabs-root-ca.crt
sudo update-ca-trust

Arch Linux:

sudo trust anchor --store rajlabs-root-ca.crt

🦊 Mozilla Firefox

Firefox maintains its own NSS certificate store separate from the operating system:

  1. In Firefox, go to Settings → search for Certificates → tap View Certificates.
  2. Select Authorities tab → tap Import.
  3. Select rajlabs-root-ca.crt.
  4. Check "Trust this CA to identify websites" and click OK.
